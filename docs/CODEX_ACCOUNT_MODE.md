# 使用本机 Codex 登录账号

MxPage 新增本机 Codex 账号模式。商品分析、页面规划、图片生成和文字描述改图通过 Codex 已登录的 ChatGPT 账号执行，不需要填写 OpenAI API Key，也不会在失败后自动切换到收费 API。

## 接入方式

调用链为：MxPage 原有业务服务 → `CodexAdapter` → 本机 `codex app-server --stdio` → ChatGPT 登录账号。

- 使用官方 App Server 协议，不是模拟网页操作，也不是反向代理私有接口。
- 登录凭据由 Codex 管理；MxPage 不读取、复制或保存登录令牌。
- 保留原有商品分析提示词、规划逻辑、图片参考素材和结果存储流程；替换的是模型调用适配器。
- 结构化返回使用固定的 `{ "json": "JSON 编码的业务结果" }` 容器；业务输入 JSON Schema 随提示提供，解码后仍执行原有 Zod 校验、默认值和转换。不把带 `transform`、可选字段或开放字典的业务 Schema 直接传给 Codex 的严格输出格式，因此不丢弃可编辑字段，也不删除原有校验。
- 从账号实际返回的模型列表选择支持图片输入的默认模型，统一承担五个工作角色。原生生图工具由该模型调用，不把某个 Images API 模型名称冒充为账号模型。
- 每次操作使用独立的临时工作目录和临时线程。完成、失败、取消或超时后关闭本次进程，并清理工作目录。
- 本次线程设置为只读、禁止审批，关闭命令执行、网页搜索、浏览器/电脑操作，以及继承的外部 MCP 和插件；不改动用户全局 Codex 配置。

## 如何使用

1. 在运行 MxPage 的同一台电脑、同一个系统用户下安装 Codex CLI，并执行 `codex login`，选择 ChatGPT 登录。
2. 执行 `codex login status`，确认是 ChatGPT 登录，而非 API Key 登录。
3. 按项目原有方式准备数据库与依赖，使用**仅监听本机**的方式启动。已有数据库默认是 `prisma/dev.db`，不要覆盖或重建已有数据。

   ```powershell
   # 已有 .env 配置 DATABASE_URL 时无需再设置此项。
   $env:DATABASE_URL = "file:./dev.db"
   # 3002 是本次使用的空闲端口；使用时先检查端口是否被占用。
   npm run dev -- --hostname 127.0.0.1 --port 3002
   ```

4. 打开本机 `/settings/providers`，点击“刷新登录状态”，再点击“启用 Codex 账号”。启用成功后显示“当前已使用 Codex 账号”。
5. 按原有工作流程创建商品项目、分析、规划及生成图片，无需填写 API Key。

如果找不到 `codex`，通过环境变量 `MXPAGE_CODEX_BIN` 指定已安装的 Codex 可执行文件完整路径，然后重启 MxPage。不要把个人机器路径或登录文件提交进仓库。

启用账号模式只停用原有 API Provider，不删除其配置。要切回 API，可展开设置页“API 服务配置”，按原有方式配置并启用。

## 与 API 模式的边界

| 项目 | 当前账号模式 |
| --- | --- |
| 计费/额度 | 使用 ChatGPT 登录下的 Codex 账号额度，受套餐、账号权限和限流约束，并非无限调用 |
| 部署位置 | 运行 MxPage 的电脑必须有可用的 Codex 登录；不是借用访问者浏览器上的登录 |
| 图片生成 | 调用 Codex 原生图片工具；实际可用性以当前账号和 CLI 为准 |
| 图片模型 | 由 Codex 管理，不保证固定为某个 Images API 模型或与 API 输出完全一致 |
| 比例、尺寸 | 通过图片任务提示表达，不保证与 Images API 的尺寸参数逐像素等价 |
| 图像修改 | 支持参考原图和文字指令改图；精确蒙版编辑明确报不支持，不静默忽略蒙版 |
| 调用监控 | 现有 API 监控页不统计此适配器的调用或账号剩余额度；不能将其 0 次理解为未消耗账号额度 |
| 服务端安全 | Host/Origin/Fetch-Site 校验限制本机同源浏览器调用；这不是用户认证，不能代替仅监听回环地址 |
| 多人/公网 | 不应把个人账号服务开放到公网或经代理共享；本次没有实现多用户认证、配额隔离和商业托管方案 |

## 官方依据

- [Codex 认证方式](https://learn.chatgpt.com/docs/auth)：ChatGPT 登录与 API Key 登录的区别。
- [Codex App Server](https://learn.chatgpt.com/docs/app-server)：账号、模型、线程与执行协议。
- [Zod JSON Schema](https://zod.dev/json-schema)：`transform` 无法直接表示为 JSON Schema；`io: "input"` 可提取转换前的输入结构。

本机接入使用官方协议，并不意味着所有套餐、所有部署方式或账号共享用途均受到支持；使用范围仍需遵守账号适用条款。
