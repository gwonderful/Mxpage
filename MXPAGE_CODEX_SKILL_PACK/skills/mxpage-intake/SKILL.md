# MxPage 项目接入

把零散输入整理为后续节点唯一可信的项目工件。

## 输入

- 项目名称或可生成的短标识。
- 至少一张商品图片；多图时必须明确或可靠识别主商品图。
- 可选：商品描述、平台、视觉风格、目标语言、详情图画幅、主图/详情图数量、额外生成要求。

## 执行

1. 读取 [工作区协议](references/workspace-contract.md)。
2. 在当前工作区创建 `mxpage-workspace/<projectId>/`；`projectId` 只使用小写字母、数字和连字符。
3. 将商品图片非破坏性复制到项目的 `assets/main/` 或 `assets/reference/`。不得移动或覆盖用户原文件。
4. 只有一张商品图时将其设为主图。多张图且主图不能可靠判断时，只询问这一项，不要继续猜测。
5. 创建 `project.json`。未提供的平台、风格、语言和详情图画幅分别使用 `generic-ecommerce`、`auto`、`zh-CN`、`9:16`；hero 画幅固定为 `1:1`，详情图画幅只允许 `3:4` 或 `9:16`。主图与详情图数量默认 4 和 6，但必须标记为默认值。
6. 创建其他标准目录和 `run-log.md`，把状态设为 `INTAKE_READY`。
7. 检查 `project.json` 中每个素材路径都真实存在，且恰好有一个 `isMain: true`。

## 输出与交接

- 返回 `project.json` 的绝对路径、主图路径、参考图数量和仍需用户补充的事实。
- 明确下一步是 `$mxpage-analyze-product`。
- 不在本节点分析卖点、规划页面或调用图片生成。
