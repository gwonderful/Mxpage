# MxPage 图片修订

把质检问题转换成低漂移、非破坏性的单轮编辑。

## 前置条件

1. 读取目标模块的当前图、生成记录和最新 review；review 状态必须为 `revise`，除非用户明确要求主动编辑。
2. 读取 [修订模式](references/revision-modes.md)。
3. 本 Skill 依赖 `$imagegen`。图片工具调用前必须读取并遵循它的编辑与保存规则。

## 执行

1. 先使用图像查看能力加载本地编辑目标，并加载主商品图作为身份参考。
2. 从 review 中选择最高严重级别的一项或一组强相关问题；每轮只做一个明确变化，避免同时重构整个画面。
3. 构造编辑 Prompt：先写要改变的内容，再逐条重复必须保持的商品身份、构图、视觉系统和正确文字。
4. 根据意图选择 `repaint`、`enhance`、`translate` 或 `regenerate`。能编辑解决时不重新生成；身份或整体构图已经错误时才重新生成。
5. 调用内置图片编辑/生成一次，把结果保存为新的 `vNNN`，保留所有旧版本。
6. 记录 `revisionMode`、来源版本、处理的 review 问题、编辑 Prompt 和新图片路径，更新当前版本并将 review 状态设回 `pending`。
7. 追加运行日志，展示新图并明确下一步再次调用 `$mxpage-review-image`。

## 停止条件

- 单一问题连续两次修订仍失败时停止自动修订，向用户呈现各版本和剩余缺陷，由用户选择重生、修改规划或接受。
- 不静默切换 CLI/API，也不覆盖已接受版本。
